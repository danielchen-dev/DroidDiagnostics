# Changelog

## 0.2.0

- Added bugreport archive inventory and dumpstate section indexing.
- Expanded subsystem coverage from 8 to 14 analyzer categories.
- Added BatteryStats/wake-lock, Binder, memory/lmkd/OOM, storage/filesystem, network and SELinux analyzers.
- Upgraded reboot, ANR, crash, kernel, biometric, display, thermal and boot analyzers with richer context and recommendations.
- Added evidence-strength labeling and removed prominent probability-like confidence UI.
- Added incident timeline, source/capability inventory and finding filters.
- Added Android bugreport structure page, technical references page and full error-signature index.
- Expanded diagnostic landing pages, engineering guides and error references.
- Added research/attribution documentation for AOSP, Battery Historian and other public prior art.
- Extended product analytics to all new finding categories.
- Added broader engine regression tests and a richer demo bugreport.
